# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in openstack-network-exporter,
please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report to the Red Hat Product Security team:

- Email: secalert@redhat.com
- https://access.redhat.com/security/team/contact/

Include a description of the vulnerability, steps to reproduce, and any
relevant logs or configuration.

You should receive a response within 5 business days.
